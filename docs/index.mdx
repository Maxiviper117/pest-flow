Pest Flow is a Pest 5 plugin for describing application behaviour with native PHP tests. It adds a small BDD-style structure around Pest's existing test runner:

~~~text
Feature
└── Rule
    └── Scenario
        ├── Given
        ├── When
        └── Then
~~~

Pest still runs every scenario as a normal test. Pest Flow gives those tests a shared vocabulary and makes their behaviour easier to read in the codebase.

:::note[Current scope]
The behaviour registry exposes discovered features, rules, and scenarios through FlowRegistry. Steps are recorded as their scenarios run. Execution results, reports, exports, and generated living documentation are planned for later milestones.
:::
